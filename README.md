# Bitacora-2-Arbol-de-expansion-minima-Prim-y-Kruskal
Problema: Determinar el subconjunto de rutas de menor costo total que interconecta todas las subestaciones sin crear ciclos en la red.  Matemáticamente, esto equivale a encontrar el Árbol de Expansión Mínima (MST) del grafo no dirigido y ponderado que modela la red.
